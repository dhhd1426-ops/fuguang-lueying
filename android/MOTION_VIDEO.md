# 视频参考与动效复刻

在聊天输入框的相册入口选择视频，或通过文件入口上传。助理可用 `inspect_video` 查看概览、`view_video_frames` 查看指定时间或局部，然后将 `source` 作为 `start_work.references` 交给后台。工具仅能读取本对话实际提供的附件。视频音频尚未转写。

后台使用同一组视频工具。每份新稿都得到递增的 `motion_revision`；`render_work_frames` 和 `compare_motion` 必须使用当前版本。参考视频复刻在本稿完成真实对比之前不能交付；对比与交付不能在同一次模型响应中执行，模型必须先收到结果。过程展开后可以查看真实帧图与对比图片。

## 时间与画面

- 参数用整数毫秒；返回图保留实际视频帧 PTS（微秒）。时间原点为第一个解码视频帧。请求时间不是实际帧时间。
- 先探测首帧时间，再使用准确输入 seek 缩小解码范围；保留原始解码时间，不插帧，不把接近的请求复制成假帧。
- `times_ms` 或 `start_ms/end_ms/count` 选择画面。每次最多 12 帧，对比最多 6 个时刻；缺失的尾部时间明确返回，不能据此判定该段已经检查。
- `crop=[x,y,width,height]` 使用归一化坐标，在缩图前裁切。参考图与作品以相同宽高比对照；`offset_ms` 显式设置作品相对参考的时间偏移，不自动改变速度。
- 对比图上排为参考、作品，下排为半透明叠加、绝对像素差。差分不代表感知相似度。
- 解码在本地进行，只按需向配置的视觉模型发送图像。当前制作模型不能看图时，由配置的视觉助手查看标注时间的图版，返回描述，界面与结果明确标记这种降级。

## 可定位时间的作品

代码与素材应自包含。提供如下接口；毫秒时间必须独立于真实运行时间：

```js
window.__motion = {
  durationMs: 6000,
  ready: Promise.resolve(),
  seek(ms) {
    // GSAP: pausedTimeline.time(ms / 1000)
    // Web Animations: animation.pause(); animation.currentTime = ms
    // Canvas/WebGL: 从确定的初态求出该时刻，或按固定步长模拟；固定随机种子。
  }
};
```

仅 CSS / Web Animations 的页面可以使用自动暂停与定位。Canvas、WebGL、嵌入视频等必须实现适配器，不能把当前静态画面当成指定时刻的画面。

预览在私有虚拟显示器上的真实 WebView 中运行，无 App 原生桥接，禁止外部导航和网络请求。等待字体、图片、动画初始化与浏览器绘制，再用 PixelCopy 读取合成结果。每批还会回到首个采样时刻复查画面是否相同；不可重复的动画返回错误。截图失败、资源缺失、超时均不构成通过。

## 保存、限额与恢复

同一视频内容、抽样时间、裁切与尺寸复用缓存。提取图缓存上限约 256 MiB；已经展示的检查证据独立保存。每次任务最多返回 192 张检查图，动画任务最多 32 轮工具调用，仍受任务总超时约束。达到限额会保留稿件与证据，不自动交付。

模型上下文只保留最近三批工具图片；更早的图片从请求中归档，保留工具 ID、时间信息与文字记录，需要时重新抽帧。原始用户照片不受这项工具图片归档影响。

后台订单保留参考附件，检查点保存最新稿件、版本与已用预算。恢复后重新建立预览并检查，不沿用已经失效的发布闭包或旧稿的通过状态。已交付作品保留参考来源，后续大改仍可查看。

## 验证

- `MotionTimesTest`：真实 FFmpeg，验证原始帧选择、重复目标、尾部缺帧、延迟视频轨道及 seek 前后时间与图像一致性。
- `node --test android/tools/motion-review.test.cjs`：需要 Playwright 和 Chromium，验证浏览器实际截图、前后定位、CSS 时间轴、异步初始化及错误处理。可通过 `CHROMIUM_PATH` 指定 Chrome。
- `MotionPreviewTest`：Android 仪器测试，验证私有显示器、PixelCopy 实际像素、无时间适配的 Canvas 拒绝、不可重复动画拒绝与资源重用。
- `check` 分支提交说明包含「视频抽帧」时启动独立的浏览器与 Android 模拟器验证；生产构建继续只包含 arm64，模拟器验证使用 `-PmotionProbe=true`。

抽样对比不能证明所有中间帧都完全一致。字体、素材、压缩、色彩与复杂物理效果仍需依据真实预览逐项判断；没有进行的检查不能标为通过。
