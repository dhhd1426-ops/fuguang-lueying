# 后台回答与作品任务

执行由应用级 ReplyRuntime 的 SupervisorJob 管理，聊天页面只观察状态。回复和 WorkJobs 分别领取唯一保活令牌，最后一个令牌释放后关闭 ReplyLive。ReplyLive 使用现有 dataSync 前台服务，并在任务期间持有定时续租的部分唤醒锁；任务结束、服务超时或销毁时释放资源。唤醒锁不能保证进程永不被回收。

每秒合并保存完整已收正文、思考、步骤和作品引用；每轮模型响应、工具执行结束、切后台时也保存。快照使用现有原子写入队列，带 interrupted 标记。恢复记录后显示“继续”，重新调用模型接着已有内容生成；这不是恢复原来的 TCP/SSE 连接。后台制作沿用现有可重试订单。

流式读取必须收到 DONE、message_stop 或合法 finish_reason/stop_reason 才能完成。长度上限单独报错。网络异常仅在本次模型请求尚未交付正文、思考或制作进度时自动重试两次，采用带随机抖动的退避；不会重跑已经执行的工具循环。部分输出中断后等待用户继续。主动停止立即关闭阻塞读取的连接并保留完整已收文字。

后台服务监听 Android 的网络 blocked 状态，写入 files/reply-runtime.log；记录服务失败、联网限制、断网、重试和任务收尾，不写提示词、密钥或原始模型输出。有实际保活/联网错误时显示系统设置入口，复用三星/小米已有设置引导。

## 验证

check 工作流先 assembleRelease，再执行 OfficeSampleTest 和 StreamRecoveryTest。后者覆盖提前 EOF、正常结束、兼容结束原因、长度上限、有限重试、不重放可见输出、退避范围及并发令牌释放。需补真机验证：发送长回答/制作作品后刷抖音、断网后返回、主动停止、结束前回收进程再打开记录、多个任务先后完成。当前没有可读取的服务端任务快照，不能照搬 DSH Go 引擎端快照同步或承诺进程被杀后自动续回原请求。
